🎓 CampusConnect

🚀 Live Demo: https://campus-connect-tau-three.vercel.app/

CampusConnect is a modern campus social platform designed to connect students, share updates, and collaborate within a university community. It helps students stay engaged with posts, events, and discussions in a simple and interactive way.
